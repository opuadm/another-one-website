# 🌐 👋 📥 another-one-website

🌐 ✨ That's just my website in html

## 🗂️ Explore the files

- 🏠 `index.html` welcomes visitors and links to the other pages.
- 📥 `software.html` contains the software download page.
- 🎨 The HTML files include their own page styling.

## 🚀 Preview the website

🖥️ Open `index.html` in a browser to view the homepage. Its existing links point to the deployed website, so they may leave the local preview.

## 🧩 Make a change

✏️ Edit the HTML files, refresh your browser, and check the navigation and download labels. The project uses plain HTML and CSS. 🌈
